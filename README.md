# Legends of Death

A handheld-style, turn-based RPG playable in a browser. Open `index.html` to play.

## Controls

- **Arrow keys** or the on-screen D-pad: move and navigate menus
- **A** / **Z**: interact, confirm, or advance dialogue
- **B** / **X**: cancel or open the menu
- **Shift**: move faster

The `styles/`, `models/`, and `scripts/` directories are organized locations for
the game's styling, visual assets, and gameplay systems.
